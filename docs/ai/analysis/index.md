# 现代分析学讲义

本讲义以 **拓扑与极限 → 微分与流形几何 → 测度与 Lebesgue 积分 → 流形积分 → 泛函分析 → 各分支** 为依赖主线。我们从具体问题引入对象，解释为什么需要新的定义，再通过证明与例子说明它能够解决什么问题。较难的核心定理展开构造和估计，辅助证明放在附录；高级专题则注明所证明的版本与进一步学习所需的工具。

建议先读[学习指南与综合自测](study-guide.md)，再按阶段学习。每章从问题出发，配有推导、例题和带提示练习；基础概念可慢读，高级选读不要求首次掌握。

不设 Riemann 积分主线，也不设独立的曲线积分、曲面积分和经典向量分析章节。第 2 章建立微分形式的代数与微分运算，第 3 章建立积分，第 4 章才定义形式的积分并证明 Stokes 定理。复积分在第 6 章作为复值 1-形式的积分出现。

## 统一约定

两份讲义统一使用 **★ 重点；○ 略讲；☆ 选读；※ 证明可跳过；△ 应用**。※ 表示首次阅读可以越过证明；省略完整证明或借用结果时，正文另行说明条件与证明范围。证明通常紧接定理，以连贯的推导展开。对于只作概述、借用高级结果或仅证明特例的地方，正文会说明范围；阅读时应连同这些说明理解结论。

实数、复数、自然数分别记为 $\mathbb R,\mathbb C,\mathbb N$，这里 $\mathbb N=\{0,1,2,\ldots\}$，正整数记为 $\mathbb N_{>0}$；数列未另说明时从 $1$ 编号；$\mathbb K$ 表示 $\mathbb R$ 或 $\mathbb C$。$\Omega$ 在分析各章默认是欧氏空间中的开集，概率章则表示样本空间，$M$ 默认是 Hausdorff、第二可数的有限维光滑流形。光滑表示 $C^\infty$；有限阶正则性会另写。

一般测度空间统一记为 $(X,\Sigma,\mu)$，第二个测度记为 $\nu$；Euclidean Lebesgue 测度统一记为 $m_n$，一维为 $m_1$，积分中的 $dx$ 表示 $dm_n(x)$。Stieltjes 测度统一记为 $\nu_F$；概率空间使用 $(\Omega,\mathcal F,\mathbb P)$，分布测度为 $\mu_X$。不同名称表示不同对象，不在后文给同一测度换名。Haar 测度与流形体积的具体约定见[共同符号约定](../notation.md#measure)。

所有积分均为 Lebesgue 积分或由它构造的积分；$L^p$ 的元素是相对于指定测度几乎处处相等的函数等价类。一般测度空间不默认有限测度或 $\sigma$-有限，定理需要时逐一注明。$\mu$ 完备表示零测集的任意子集可测，与度量空间完备是不同概念。

复 Hilbert 空间内积对**第一变量线性**，对第二变量共轭线性。分布与对偶泛函采用线性而非共轭线性约定。代数对偶与连续对偶都记为星号，但会明确空间类别；对偶映射记为 $T^*$，内积伴随统一记为 $T^\dagger$。两者的区别、Fourier 归一化与外积约定见[共同符号约定](../notation.md)。Euclidean Laplace 算子取

$$
\Delta=\sum_{j=1}^n\partial_j^2.
$$

Fourier 变换取 $\widehat f(\xi)=\int_{\mathbb R^n}f(x)e^{-2\pi i x\cdot\xi}\,dx$，因此 $\widehat{\partial_jf}=2\pi i\xi_j\widehat f$。流形边界取“外法向优先”的诱导定向。各章统一使用这些符号与正负号。

## 如何使用本讲义

先准确识别对象与假设，再使用定理。尤其区分：逐点与一致收敛、几乎处处与依测度收敛、闭形式与恰当形式、局部鞅与真鞅、经典解与弱解。建议先完成每章末的练习，遇到反例时回查缺失条件。
